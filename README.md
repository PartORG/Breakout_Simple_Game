# Breakout Simple Game

A classic breakout game written in Python, providing a simple and engaging experience.

## Requirements

- Python 3.8 or higher

## Installation

To install and run the game, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/PartORG/Breakout_Simple_Game.git
   cd Breakout_Simple_Game
   ```

2. Install dependencies using pip:
   ```sh
   pip install -r requirements.txt
   ```

## Usage

To run the game, execute the following command:

```sh
python breakout.py
```

This will start the game in your default Python environment. Enjoy playing!
